**Project Title:** Personal Portfolio Website

## 1. Objective
To design and develop a responsive personal portfolio website that presents the student's introduction, skills, projects, and contact information, and to publish the website using GitHub Pages.

## 2. Technologies Used
- HTML5 — page structure and content
- CSS3 — styling, responsive layout, and animations
- JavaScript — mobile navigation, scroll reveal effects, and contact form behavior
- Git and GitHub — version control and source-code hosting
- GitHub Pages — static website deployment

## 3. Project Description
The portfolio website includes Home, About, Skills, Projects, and Contact sections. It uses a consistent dark theme with a bright accent color, responsive layouts, project cards, and mobile navigation. The contact form prepares an email using the visitor's default email application.

## 4. Main Features
1. Responsive design for desktop, tablet, and mobile devices.
2. Navigation links to each section.
3. Introduction and profile summary.
4. Skills cards with illustrative progress bars.
5. Project cards with technology tags and repository links.
6. Contact form with basic field validation.
7. Scroll reveal animations and hover effects.
8. Ready for deployment using GitHub Pages.

## 5. How to Run
Open `index.html` in a modern web browser. For publishing, upload the files to a public GitHub repository and enable GitHub Pages from the `main` branch and root folder.

## 6. Output
The output is a responsive personal portfolio website. Add screenshots of the Home, Skills, Projects, and Contact sections after running the site and paste them into the final report.

## 8. Conclusion
This project demonstrates the use of HTML, CSS, and JavaScript to build a responsive website and the use of GitHub for version control and GitHub Pages for deployment. It provides a central place to showcase student skills and projects.
