# Preet Rana — Personal Portfolio Website

A responsive personal portfolio website developed for the **IT4048: Version Control with Git and GitHub** mini-project.

## 1. Project Files

- `index.html` — Website structure and portfolio content.
- `style.css` — Website styling, responsive layout, and animations.
- `script.js` — Mobile navigation, reveal animations, and Gmail contact form.
- `assets/` — Folder for profile photos, résumé, and other resources.

## 2. Project Setup and Usage

1. Download or clone the project repository.
2. Open the project folder.
3. Open `index.html` in a web browser to view the website.
4. Update the portfolio content, skills, profile links, and résumé as required.

## 3. Publishing Using GitHub Pages

1. Create a public GitHub repository.
2. Upload all project files and folders to the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/(root)` folder.
6. Click **Save** and wait for the website to be published.
7. Open the published URL and test the website on a computer and mobile device.

## 4. Important Notes

- This is a static website developed using HTML, CSS, and JavaScript. It does not require PHP, Python, or a database.
- The contact form opens Gmail in a new browser tab with the recipient, subject, and message prepared. The visitor must click **Send** to send the email.
- The résumé button works when the résumé PDF is placed in the `assets/` folder and the correct file path is configured in `index.html`.
- Website updates can be published by uploading revised files and committing the changes to GitHub.
