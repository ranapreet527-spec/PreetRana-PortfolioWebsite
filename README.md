# Preet Rana — Personal Portfolio Website

A responsive personal portfolio built for the IT4048: Version Control with Git and GitHub mini-project.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive layout, theme, and animations
- `script.js` — mobile navigation, reveal animations, and email form behavior
- `assets/` — place your profile photo and résumé here

## Before submission
1. Replace `your.email@example.com` in `index.html` and `script.js` with your real email.
2. Replace the sample GitHub links with links to your own repositories.
3. Replace `assets/Preet_Rana_Resume_Template.pdf` with your final résumé PDF (keep the same filename, or update the link in `index.html`).
4. Check all content and skill progress bars so they reflect your actual experience.
5. Open `index.html` in a browser to test locally.

## Publish using GitHub Pages
1. Create a public repository named `PreetRana_PortfolioWebsite`.
2. Upload all files and folders in this project.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the published URL shown in the Pages settings.
7. Test the live site on both phone and computer.

## Notes
- This is a static site and does not require PHP, Python, or a database.
- The contact form opens the visitor's email application; it does not send or store messages by itself.
- The résumé button should be added/updated once you place your résumé PDF in the project.
